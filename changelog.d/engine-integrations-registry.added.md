- **Integrations registry: QuickBooks, Egnyte and Microsoft 365 connection definitions, and an admin page.** The engine now ships a connection definition for each (URLs, scopes, token behaviour, a one-call describe of the account; no reader). A host enables one in an initializer with `Studio.enable_integration :quickbooks, env: { client_id: "...", client_secret: "..." }`, naming its own env vars, and mounts `Studio.draw_integrations_routes(self)`: `/admin/integrations` lists each status and Connect, and `/admin/integrations/<key>` shows its connections, Disconnect, the redirect URI to register (`/admin/integrations/<key>/callback`) and the host's own panel (`panel:`). Stand-ins walk a connect end to end in development and test. See `docs/INTEGRATIONS.md`.
