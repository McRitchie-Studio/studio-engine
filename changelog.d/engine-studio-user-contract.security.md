- **The engine's sign-in doors find nobody for a blank email.** `SessionsController#create` and the SSO "Continue as" path looked the account up with `User.find_by(email: ...)`. With no address that is `find_by(email: nil)`, which matches any account without an email (a wallet or guest sign-up): the password door handed that account to `authenticate`, and the SSO path signed it in. Both now use `Studio::Account.find_by_email`, which also matches case-insensitively. Nothing for a consumer to change.
