- **The not-found page runs no session tracking and no geo detection.** `Studio::NotFoundController` runs as the exceptions app, outside the session and cookie middleware, so a session-throttled callback never holds there. It added a `Studio::UserSession` row on every signed-in 404, and an app with `Studio::GeoDetection` paid an IP geo lookup (up to 3s) on every 404. The controller now overrides `track_user_session` and `detect_geo_state` as no-ops. The callbacks stay registered, so an app that already skips them in its own initializer (Turf does) still boots; it can drop those lines after it bumps the engine. See `docs/NOT_FOUND_PAGE.md`, *What it skips*.
