- **The not-found page skips session tracking and geo detection.** `Studio::NotFoundController` runs as the exceptions app, outside the session and cookie middleware, so a session-throttled callback never holds there. It added a `Studio::UserSession` row on every signed-in 404, and an app with `Studio::GeoDetection` paid an IP geo lookup (up to 3s) on every 404. The controller now skips `track_user_session` and `detect_geo_state` (`raise: false`). An app that skipped them in its own initializer can drop that code after it bumps the engine. See `docs/NOT_FOUND_PAGE.md`, *What it skips*.
